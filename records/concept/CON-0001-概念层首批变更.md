# CON-0001 · 概念层首批变更（民法典概念骨架）

## 1. 变更前

- `ontology/tbox/` 7 文件，无任何法律概念类（`law:法律概念` 下 0 个子类）。
- `wiki/concepts/` 0 页；`retrieval/manifest.json` 0 概念块。
- 概念层的一切「是什么」均无处可查，规则层与案例层也无 IRI 可引用。

## 2. 变更后

新增 445 个概念类（`law:法律概念` 的间接子类），全部 `判断状态=候选`、`溯源状态=溯源-投递材料`。

| 模块 | 条数 | 主要来源 |
| :--- | ---: | :--- |
| 主体模块 | 311 | 主体词条 279（298 − 19 条重叠）+ 释义主体概念 32 |
| 关系模块 | 83 | 物权、合同、人格权、继承、准合同 |
| 行为模块 | 22 | 意思表示、身份行为、处分行为 |
| 效果模块 | 22 | 责任形态、损害赔偿、抗辩事由 |
| 规范模块 | 1 | 仅 `民法` |
| 待裁定 | 6 | `不可抗力` `期间` `诉讼时效` `占有` `添附` `善意取得` |
| **合计** | **445** | 释义 166 + 主体词条 298 − 重叠 19 |

字段填充情况：

| 字段 | 有值条数 | 说明 |
| :--- | ---: | :--- |
| `law:定义` | 166 | 仅释义条目有定义；主体词条无定义，只有出现统计 |
| `law:规范条号` | 166 | 释义给出的条号（未逐条比对现行文本） |
| `law:来源文本` | 445 | 释义条目写「《民法典》第N条」；主体词条写「主体名词，首次出现第N条」 |
| `law:出现次数` / `law:涉及条文数` / `law:首次出现条号` / `law:清单备注` | 各 298 | 均来自投递清单，未由系统复核 |
| `law:锚定能力问题` | 445 | `CQ-M01` + 模块功能锚点 |

## 4. 需回测的能力问题

| 编号 | 回测方式 | 当前结果 |
| :--- | :--- | :--- |
| `CQ-M01` | 每个概念恰有 1 个模块上位类；无悬浮 | 439/445 通过；6 条按 ADR-0012 §2.5 走待裁定豁免 |
| `CQ-M04` | 溯源率 ≥90% | 445/445 有溯源（投递材料），但**「有溯源」不等于「溯源合格」**：投递材料只能支撑候选，故 M04 的实质性验收仍未达成 |

## 5. 迁移方式

1. 改判模块归属：修 `tools/import/import_civil_code.py` 的 `SECTION_MODULE` / `NAME_OVERRIDE` / `PENDING_REASON`，重跑，`71-*.ttl` 与 `module-assignment.tsv` 同步更新。
2. 概念升格（`候选 → 已验证`）：须先有规范原文（ESC-0002 选项 A），逐条附条号、版本、复核者；本批**不得**批量升格。
3. 概念废弃：不删 IRI，标 `判断状态=已否定` 并保留（ADR-0005）。
4. 回退：删除 `71-concepts-civil-code.ttl` 与 `70-concept-metadata.ttl`，重跑 `tools/sync` 与 `tools/vis`，恢复 PROV 上一版本指纹登记。
