# ADR-0009 · 范围策略与子领域选择（proposed）

> **状态说明**：本 ADR 为 `proposed`。子领域选择是范围决策，裁定权在项目负责人（§二.1）。已开 `ESC-0001`，`blocking` 于阶段 2 及之后的概念/规则/案例建设。本 ADR 不构成生效约束。

## 1. 决策（待确认）

- **范围策略**：单一子领域深挖，不做多子领域并行覆盖。
- **建议子领域**：A · 买卖合同价款请求权（出卖人请求买受人支付价款）。
- **备选**：B · 民间借贷利息争议（约定利息、逾期利息、利率上限）。

## 2. 选项对比（只列后果，不给推荐）

| 维度 | A 买卖合同价款请求权 | B 民间借贷利息争议 |
| :--- | :--- | :--- |
| 要件结构复杂度 | 中：合同成立生效、标的物交付/交付义务、价款约定、履行期届至 | 中偏高：借贷合意、款项交付、利率约定、逾期事实、利率上限规则 |
| 开放纹理要件 | 有（「合理期限」「质量不符合约定」类） | 明显更多（「高利」「变相利息」「显失公平」） |
| 辅助规范（司法解释）密度 | 较高（买卖合同司法解释） | 高（民间借贷司法解释，且历经修订，版本双层价值大） |
| 案例可得性 | 高（裁判文书存量大、说理模板化） | 高（但案件事实更碎片、口头约定多） |
| 因子区分度 | 中（交付凭证、验收记录、催告等较易识别） | 中偏高（转账记录、聊天记录、砍头息等辨识度高） |
| 与四元决策的贴合度 | 版本双层需求中等 | **版本双层需求强**（利率上限规则多次调整），能更早检验 ADR-0003 |
| 主要风险 | 与「质量抗辩」交织，可能引出瑕疵担保这一独立规则群，范围易膨胀 | 利率上限涉及金融监管口径，易越出民事范围；且部分争议需专业金融判断 |

## 3. 放弃方案与代价

| 方案 | 放弃原因 | 代价 |
| :--- | :--- | :--- |
| 多子领域并行（买卖 + 借贷 + 租赁） | 首批 30–50 因子与 10 案例的标注量下，多子领域会导致每领域覆盖不足，因子词表无法收敛（§阶段 4「自下而上收敛」失效） | 泛化性看起来更好，但每个领域都停在「演示级」，无法通过阶段 5 回测 |
| 选侵权责任（过错 + 因果关系） | 开放纹理要件过多（过错、因果关系、损害范围），首版无足够裁定源，ESC 会挤爆 | 更能体现类比，但阻塞风险最高 |

## 5. 复审触发条件

- 首批 10 案例若因子无法从 ≥70% 样本可靠识别 → 触发子领域切换判据（§十），按 `PLAN/01` §5.3 执行。
- 若负责人在 ESC-0001 中选择 B，则本 ADR 改写为 accepted 并替换建议项。
