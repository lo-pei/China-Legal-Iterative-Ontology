# RSK-0003 · 记录开销侵蚀建模时间

## 1. 风险描述

§十 治理降级规则：「若阶段 2 结束时记录撰写时间超过实际建模时间 40%，触发 META 审查，评估裁减记录类型」。

本轮为自举轮，需一次性建立 10 份 ADR、6 份 RSK、3 份 ESC、ITER、META、INDEX、SCHEMA、AGENTS 及工具链，记录量天然高于稳态。**但本轮的比值不能作为稳态估计**，若据此裁减记录类型，会在制度尚未跑通时破坏治理基础。

## 2. 观测口径（避免主观判断）

以「本轮新增 markdown 文件的行数」作为记录成本的代理指标，以「本轮新增 ttl 与 py 文件行数」作为建模成本的代理指标，二者比值记录于 `META-0001` §3。该口径可重复计算，不依赖主观估计。

## 3. 缓解措施

1. 记录模板化：`SCHEMA.md` §6 给出各记录类型的最小骨架，避免每次从零组织。
2. 禁止空转记录：无对应事件的记录类型不写（本轮无 CON，因无法律概念变更；此点已在 LOG 说明）。
3. 工具承担机械劳动：`INDEX.md` 的「最近 LOG / RSK / ESC 列表」由 `tools/sync` 生成段落，人工只维护叙事部分。

## 4. 触发处置

阶段 2 结束时若比值 >1.5（即记录行数超过建模行数的 1.5 倍，含历史累计）→ 按 §十 提 META，并提交裁减 ADR（首批候选：CHG 并入 LOG、ACC 与 META 合并）。`ADR / CON / ITER / ESC` 不可裁减。
