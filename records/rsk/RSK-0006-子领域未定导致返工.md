# RSK-0006 · 子领域未定导致的返工风险

## 1. 风险描述

`ESC-0001`（子领域与范围冻结）尚未裁定。若在此之前开始建设因子词表或标注案例：

- 因子词表是**自下而上收敛**的（§阶段 4 决策），收敛结果高度依赖所选子领域的案例分布。买卖合同的因子（交付凭证、验收异议期）与民间借贷的因子（转账凭证、砍头息、复利约定）几乎无交集。
- 词表一旦被规则层的构成要件以 `law:锚定要件` 引用，替换成本不是重命名，而是**重建锚定关系**，且历史案例的因子画像全部失效。

## 2. 已采取的预防（本风险当前处于「已抑制」状态）

1. 本轮的 tbox 只含元模型，**不含任何因子词表项**。`ontology/abox/vocabulary/` 保持空目录 + README。
2. 阶段 1 的结构演练样本（`tools/validate/fixtures/STRUCT-DRYRUN.ttl`）使用显式占位标识（`演练-要件A` 等），并带 `law:非法律结论 true` 与 `law:演练标记 true`，不指向任何真实法律概念，因此不会被子领域切换影响。
3. 概念层与规则层均未开工，切换成本当前为零。

## 3. 若不抑制的后果

按 ADR-0009 §2 的对比，若先按 A（买卖）建词表后改判 B（借贷），预计需废弃 100% 因子词表项与已标注案例的因子画像，仅可保留规则结构骨架。这与 §十 回退预案中「必须废弃」档位对应。

## 4. 复审触发条件

`ESC-0001` 裁定后立即关闭本风险或转为具体返工任务；若超时未裁定，本风险升级为 `blocking`，并在 `INDEX.md` 升级队列置顶（§十 僵局规则）。
