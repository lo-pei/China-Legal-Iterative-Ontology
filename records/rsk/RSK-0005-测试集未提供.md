# RSK-0005 · 测试集未提供

## 1. 风险描述

§二.1 规定测试集「阶段 5 前提供」。当前为空，直接后果：

- §5.3 标注 F1（≥0.8）无法测量——无金标准可比对。
- 阶段 5 的「演绎链回测」「因子比较有效性」「归纳可检验性」三条检验全部无法执行。
- 能力问题清单中，凡验收判据为「与测试集结论一致」的条目只能标 `依赖测试集`。

## 2. 影响面与替代

不影响阶段 1–4 的结构性产出与内部检查。内部检查（§阶段 5「内部检查」四项）**不依赖测试集**，可先行完成：

1. 逻辑一致性（类层级可满足性、规则结构完整性）→ `tools/validate` 已实现。
2. 结构完整性（因子—关键事实—构成要件链连通）→ 校验器已实现链连通检查。
3. 协同指标（是否存在未被演绎消费的类比节点 / 未进规范层的归纳输出）→ 校验器已实现 `W-UNCOUPLED`。
4. 元设计稳定性（阶段 2 期间元设计是否发生结构性修改，目标为零）→ 以 tbox 文件 hash 与 tag 比对实现。

## 3. 缓解措施

- 测试集接入协议已写入 `PLAN/01-scope-freeze.md` §6，负责人投递后可直接执行。
- 已明确：测试集结果**不得进入 ontology**，只写 `records/acc/`（§9.1 第 3 条）。此约束已在 `AGENTS.md` 硬约束中重复。
