# ESC-0003 · 复核者与一致性测量机制

## 1. 待裁定事项（一句话）

标注质量门禁 3（≥10% 盲审）与 §5.3 的 Cohen's κ 一致性指标由谁执行？

## 2. 系统为何无法裁定

这属于治理角色分配，不是结构性判断。系统不能自行担任复核者：§5.2 门禁 3 要求复核者「未参与标注」，同一主体既标注又复核会使复核字段失真，并让 κ 恒等于 1，导致指标虚高——这比不测量更危险，因为它会在验收报告上制造可信的假象。

同时，系统也不能自行决定「不设复核者、全部标候选」，因为那等于单方面降低 §5 的标注质量标准。

## 3. 系统已尝试

1. 已在数据模型中把 `law:标注者` 与 `law:复核者` 设为独立属性，并在校验器加入 `W-SELFREVIEW` 检查（同批内相同即报警）。
2. 已确认：本 ESC 不阻塞阶段 1 元设计与工具链工作，也不阻塞阶段 4 的**结构**标注（因子画像的骨架、要件判定记录的字段填充），只阻塞「把标注升为 `已验证`」这一动作。
3. 已评估「由系统自标 + 明确降级」的可行性：技术上可行，但必须在所有下游明确该批标注为单标注（single-annotator），κ 不可报告。这属于质量标准变更，需负责人确认，系统不得自行采用。

## 4. 阻塞什么

| 阻塞对象 | 说明 |
| :--- | :--- |
| 标注升 `已验证` | 无复核者不得升级 |
| §5.3 的 κ 与错误注入检出率 | 无法测量 |
| 阶段 4「10 个经专家核验的案例」 | 「专家核验」需外部角色 |
| 阶段 5 的 ACC 验收报告 | F1 与 κ 两项指标缺项 |

**不阻塞**：阶段 1 元设计、工具链、投影管线、记录体系、`pending-escalation` 机制演练。

## 5. 建议裁定选项与各自后果

### 选项 A：指定第二复核人（人类）

后果：门禁 3 与 κ 全程可测，标注可升 `已验证`，阶段 5 验收报告完整。代价：需第二名具备法律背景的人员投入，复核量为批次 10%（κ 测量需双标批次）。

### 选项 B：负责人亲自抽样复核

后果：合规（负责人即为未参与标注者），但复核吞吐受负责人时间限制，可能成为阶段 4 的瓶颈。κ 只能在「双标注子批」上计算（约 20–30 条样本），统计效力有限但可报告。

### 选项 C：系统单标注，标准降级

后果：所有标注永久停留 `候选`，不允许升 `已验证`；`ACC` 报告中 F1 与 κ 标记为「不可测量（单标注）」。项目可继续推进，但「大厂级标注质量可校验」这一交付约束**无法成立**，必须在交付说明中明示。系统需为此写 ADR 记录标准降级，并由负责人确认接受。

## 6. 裁定方式

在 `resolution` 字段写明选项；若选 A，请说明复核人身份与可用工时；若选 C，请确认接受「标注质量不可校验」的交付后果。
